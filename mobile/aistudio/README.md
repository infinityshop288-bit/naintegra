# NaIntegra Lex → Google AI Studio

## Início rápido

```bash
cd mobile
npm run export:aistudio
```

Abra: **https://aistudio.google.com/apps?source=start**

1. **Build an Android app**
2. Cole o prompt de `PROMPT.md` (ou do ZIP gerado)
3. Anexe `assets/icon-512.png`
4. Teste no emulador → **Connect Play Console** → **Internal Test Track**

## Arquivos

| Arquivo | Uso |
|---------|-----|
| `PROMPT.md` | Prompt para colar no AI Studio |
| `app-spec.json` | Metadados técnicos (package, URLs) |
| `../store-assets/google-ai-studio.md` | Guia completo |
| `../dist/naintegra-lex-aistudio.zip` | Pacote gerado (após export) |
